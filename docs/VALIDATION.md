## Browser coverage

`tests/browser-smoke.py` exercises the real bundled Worker, changes specifications, reconnects blocks, solves a newly created model, runs sensitivity, converts temperature units, drags and deletes nodes, restores topology with undo/redo, and imports a project file. See `browser-validation.json` for the executed checks.

The browser test uses an opaque about:blank context and the **Canvas 2D fallback**. The WebGPU code path is implemented but was **not runtime-validated or hardware-benchmarked in the delivery environment**. Test the WebGPU backend on a supported browser served from localhost or HTTPS before deployment.

## Verification boundary

The Antoine coefficient test checks transcription and evaluation. The approximate normal-boiling check is not a full vapor-pressure validation. Constant heat-capacity, vaporization-enthalpy and density assumptions have not been calibrated against plant data. No comparison to Aspen Plus results is asserted.
